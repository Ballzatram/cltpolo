# Security

Do not include credentials, personal data or exploit details in public issues. For this currently local workspace, report security issues directly to the repository owner through an existing private channel. Before sharing this repository, replace this instruction with a tested private reporting route and monitored contact.

Owner: Ballzatram. Supported baseline: 1.x, with upgrades managed through reviewed changes. Consumer projects must declare their own supported software versions and reporting route.

Treat suspected exposed secrets as compromised: revoke or rotate them, investigate use, and remove them from current files and history where appropriate. Deleting a file alone is insufficient. Follow [security requirements](docs/security.md).
