# Project engineering instructions


## Shared engineering baseline

This repository adopts Engineering Standards 1.0.0, pinned in `.standards.json` and vendored in `.engineering/`. Read the selected profiles, preserve existing product behavior, and run the project checks documented in `docs/standards-adoption.md`. Existing instructions remain in force. Do not relax security, change economic/scientific assumptions, enable paid/live operations, or claim conformance to obtain a green check. Keep gaps explicit in `docs/audit.md`.
